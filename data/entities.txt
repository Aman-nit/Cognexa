### claim
Entity: claim
Business Name: Claim
Primary Key: claim_id
Synonyms: claim, insurance claim, loss claim

The monetary claim filed against a policy for a given incident.

Attributes:
  - claim_id (Claim Identifier, type: BIGINT)
  - incident_id (Incident Reference, type: BIGINT)
  - total_claim_amount (Total Claim Amount, type: INTEGER)
  - injury_claim (Injury Claim Amount, type: INTEGER)
  - property_claim (Property Claim Amount, type: INTEGER)
  - vehicle_claim (Vehicle Claim Amount, type: INTEGER)
  - fraud_reported (Source Fraud Label, type: VARCHAR)

### incident
Entity: incident
Business Name: Incident
Primary Key: incident_id
Synonyms: incident, accident, event, occurrence

The event that led to a claim being filed.

Attributes:
  - incident_id (Incident Identifier, type: BIGINT)
  - policy_number (Policy Reference, type: BIGINT)
  - incident_date (Incident Date, type: DATE)
  - incident_type (Incident Type, type: VARCHAR)
  - collision_type (Collision Type, type: VARCHAR)
  - incident_severity (Incident Severity, type: VARCHAR)
  - authorities_contacted (Authorities Contacted, type: VARCHAR)
  - incident_state (Incident State, type: VARCHAR)
  - incident_city (Incident City, type: VARCHAR)
  - incident_location (Incident Location, type: VARCHAR)
  - incident_hour_of_day (Incident Hour, type: INTEGER)
  - vehicles_involved (Number of Vehicles Involved, type: INTEGER)
  - property_damage (Property Damage Reported, type: VARCHAR)
  - bodily_injuries (Bodily Injuries Count, type: INTEGER)
  - witnesses (Witness Count, type: INTEGER)
  - police_report_available (Police Report Available, type: VARCHAR)

### insured
Entity: insured
Business Name: Policyholder
Primary Key: insured_id
Synonyms: insured, customer, policyholder, client

Person insured under an insurance policy.

Attributes:
  - insured_id (Customer Identifier, type: BIGINT)
  - insured_zip (Insured ZIP Code, type: INTEGER)
  - age (Customer Age, type: INTEGER)
  - gender (Gender, type: VARCHAR)
  - education_level (Education Level, type: VARCHAR)
  - occupation (Occupation, type: VARCHAR)
  - hobbies (Hobbies, type: VARCHAR)
  - relationship (Insured Relationship, type: VARCHAR)
  - capital_gains (Capital Gains, type: INTEGER)
  - capital_loss (Capital Loss, type: INTEGER)

### policy
Entity: policy
Business Name: Insurance Policy
Primary Key: policy_number
Synonyms: policy, coverage, insurance policy, contract

Coverage contract issued to a policyholder.

Attributes:
  - policy_number (Policy Number, type: BIGINT)
  - insured_id (Policyholder Reference, type: BIGINT)
  - months_as_customer (Customer Tenure (Months), type: INTEGER)
  - policy_bind_date (Policy Start Date, type: DATE)
  - policy_state (Policy State, type: VARCHAR)
  - policy_csl (Combined Single Limit, type: VARCHAR)
  - policy_deductible (Policy Deductible, type: INTEGER)
  - policy_annual_premium (Annual Premium, type: FLOAT)
  - umbrella_limit (Umbrella Coverage Limit, type: INTEGER)

### vehicle
Entity: vehicle
Business Name: Covered Vehicle
Primary Key: vehicle_id

Attributes:

  - auto_make (Vehicle Make, type: VARCHAR)
  - auto_model (Vehicle Model, type: VARCHAR)
  - auto_year (Vehicle Year, type: INTEGER)
